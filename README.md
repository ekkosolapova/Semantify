# Semantify

**Программный комплекс автоматизированной потоковой семантизации и иерархического сегментирования каталогов SKU потребительских товаров.**

Интеллектуальная система разработана в рамках выпускной квалификационной работы (ВКР) и предназначена для автоматической нормализации, категоризации и сквозного извлечения атрибутов номенклатурных позиций (на примере категорий «Бритвы» и «Канцелярские товары»).

---

## Архитектурные компоненты комплекса

Программа реализует **двухконтурную систему защиты качества данных**:
1. **Первый контур (ИИ-инференс и Веб-парсинг):** Текстовый энкодер `ruBERT-tiny2` преобразует зашумленные наименования в 312-мерные семантические векторы. Каскад моделей `CatBoostClassifier` осуществляет пошаговую иерархическую классификацию (Категория → Сегмент → Тип). При падении кумулятивной уверенности ниже порога $\gamma_{parser}$ активируется модуль веб-обогащения контекста маркетплейсов.
2. **Второй контур (Интерактивная верификация):** Если уверенность каскада ниже порога $\gamma_{operator}$, позиция направляется на вкладку ручной проверки. Интерфейс на `Tkinter` поддерживает сквозное модальное редактирование ячеек, удаление и добавление строк с синхронизацией ОЗУ и кэша данных в `Pandas`.

## Структура репозитория и файлов проекта

Для корректной работы комплекса все бинарные файлы и файлы нормативно-справочной информации (НСИ) должны находиться в одной директории со скриптом:

*   `Semantify.py` — монолитный исходный код графического интерфейса пользователя (GUI) и логики инференса.
*   `category_model.bin` — обученная ИИ-модель CatBoost 1-го уровня (определение Категории).
*   `segment_model.bin` — обученная ИИ-модель CatBoost 2-го уровня (определение Сегмента).
*   `type_model.bin` — обученная ИИ-модель CatBoost 3-го уровня (определение Типа товара).
*   `Структура ВС (5).xlsx` — файл внешней методички НСИ (динамические справочники эталонных саббрендов мировых производителей и карты цветов).
*   `настройки.json` — конфигурационный файл сохранения пользовательских барьеров и путей.
*   `Запуск.bat` — командный скрипт для мгновенного развертывания виртуального окружения и старта GUI приложения.

## Требования к окружению и запуск

Комплекс оптимизирован для работы на CPU и дискретных видеокартах с поддержкой архитектуры NVIDIA CUDA.

### Ключевые зависимости (Python 3.10+):
```bash
pip install pandas numpy torch transformers catboost openpyxl requests beautifulsoup4
```

### Запуск приложения:
Выполните инициализацию через командный файл или запустите напрямую из терминала:
```bash
python Semantify.py
```

## Результаты разметки и выходные данные

Система осуществляет экспорт нормализованного каталога в формат `.xlsx`. Итоговая таблица строго соответствует ГОСТу и структуре бакалаврского исследования, распределяя характеристики по 18 аналитическим колонкам:
*   *Идентификаторы и ИИ-сегменты:* ID, Наименование номенклатуры, Категория, Сегмент, Тип товара.
*   *Физические свойства SKU:* Пол, Кол-во лезвий, Кол-во в уп, Объем/вес, Производитель, Бренд, Саббренд.
*   *Специфичные атрибуты:* Механизм, Твердость карандаша, Цвет, Толщина письма, Формат упаковки, Дополнительные свойства.
